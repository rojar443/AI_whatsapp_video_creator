# Licensed music library

Put royalty-free / licensed tracks here and list them in `library.yaml`. Only listed tracks
with a `license` are used. Without any, ReelChat synthesises a calm ambient bed (labelled
"generated") so demos still have music.

```yaml
- file: calm/sunrise-walk.mp3
  title: Sunrise Walk
  artist: Example Artist
  license: "Pixabay Content License"         # keep proof of the licence
  source_url: https://pixabay.com/music/...
  moods: [calm, inspiring]
  energy: low                                # low | medium | high
```

Check each licence allows use in social-media videos made for your users.
